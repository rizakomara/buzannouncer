# buzannouncer
Android-based software for Public Transport Announcer using Car Android Head Unit.
Please use Android Studio to compile and deploy.

Capabilities:
1. Bus stop Voice Announcer based on GPS Coordinates
2. Custom Voice Announcement
3. GPS Tracking Capability, when your Head Unit have 4G LTE capability.
4. Integrate with other equipment's such as Running Text Display and Media Player, using RS485 communication.

Preparation:
1. Android Car Head Unit, please choose minimum 4GB RAM, you can choose 7 inch, 9 inch or 10 inch touch screen display. 4G LTE features will be an advantages.
2. A CH340 USB to Serial/RS485 for other equipment integration (optional)
3. We recommend using File Manager+ to manipulate files on your Head Unit.
